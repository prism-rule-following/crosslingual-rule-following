# How to review the translations

Thank you for helping. This is everything you need — about four minutes to read,
and no technical knowledge required.

## What you are doing

We had a computer translate a dataset from English into your language. You are
checking its work, one record at a time.

<!-- You are **not** rewriting things into nicer language. If a line already says the
same thing as the English, leave it exactly as it is, even if you would have
phrased it differently. Only change what is actually wrong. -->

## Getting in

1. Open the link you were sent.
2. Log in/signup with your email and password
3. Click the project with your language in its name.
4. Click **Label All Tasks**. The first record appears.

<!-- Everything else on that screen — Import, Settings, the menus — is not for you,
and will refuse if you click it. Nothing you do can break the project. -->

## What one record looks like

Each record is one test case. At the top is a grey box with its reference
number and some technical details (its id, category, and the rule used to grade
it). That box is for information only

Below it, the record is laid out side by side:

- **English.** The original. It is always right.
- **your language below the English.** The computer's translation, in editable boxes.

Each row is one part of the record: the rule text, the user's question, and so on. The number of rows varies — some records have more
parts than others.

## What to do

Go down the rows. For each one:

- **If the translation is fine**, do nothing at all. Move to the next row.
- **If it is wrong**, click in the box and fix it. The current translation is
  already there, so usually you are changing a word or two, not retyping.

When you have been down every row, click **Submit**. The next record loads.

Anything you didn't touch is kept exactly as it was — leaving a box alone is
how you say "this one is correct".

## Four things that matter

**Quotation marks.** Some lines contain a word inside quotes, like
`Never use the word 'promise'`. A computer later searches for that exact quoted
word, so keep it inside its quotes — and make sure the quoted word is the
translated one, not the English one.

**Angle brackets.** Some answers contain `<b>` and `</b>`. Leave them exactly
where they are, letter for letter. They are not words and must not be
translated.

**One keyword per line.** The keywords row holds a list. Keep one keyword on
each line — don't join them with commas.

**Some rows repeat each other on purpose.** The "system rule" row is the
context and the rule joined into one line. If you change the rule, change it in
the system rule row too, the same way.

## The note box

At the bottom of every record there is an optional note box. Use it when
something is genuinely unclear — the English is confusing, or there are two
reasonable translations and you don't know which is wanted. Write the note,
leave the text as it is, and submit. Someone will look at it.

**Please use the note instead of guessing.**

## Things people ask

**The translation is understandable but slightly awkward.** Leave it. Only fix
meaning that is wrong, words that are missing, or phrasing no one would say.

**An answer is in French, not my language.** That is deliberate — a few records
test whether an AI can answer in French. Leave it alone.

**The question is rude, or strange.** Also deliberate. Some records test how an
AI handles a hostile or odd question. Translate the tone as it is; don't soften
it.

**I made a mistake on a record I already submitted.** Click the project name at
the top, find the row in the list, click it, fix it, and submit again.

**Do I have to finish in one sitting?** No. Each record is saved when you
submit it. Close the tab and come back whenever you like.

**Something looks broken, or the same record keeps appearing or have further questions.** Reach out.
